# 景区导览小程序

> 纯本地离线运行 · 不依赖任何后端 · 可直接演示

---

## 一、项目定位

一个面向景区游客的**离线导览**微信小程序。内置西湖、灵隐、良渚三处景区的导览数据，支持景点浏览、目录直达、打卡留念与游览进度统计。

**核心设计原则**：完全离线、零后端、即开即用。整个小程序不发起任何网络请求，所有数据内置、所有状态存本地——断网也能完整使用。

---

## 二、功能特性

| 功能 | 说明 |
|---|---|
| 景区列表 | 一屏列出全部景区，含景点数量与「已浏览 X%」进度可视化 |
| 景点浏览 | 逐段浏览某景区下的景点（简介 + 景点详情），退出后进度精确恢复 |
| 游览进度 | 自动统计已浏览景点百分比，列表页实时展示 |
| 离线封面图 | 3 张景区真实网图内置本地，列表项内联展示，离线可用 |

### 字段定义
- **已浏览 X%**：已浏览景点数 ÷ 景区景点总数，反映「看到了第几个」。
- **打卡 N**：用户主动点击「打卡」的景点计数，写入本地缓存。
- 两者语义不同、独立统计：已浏览是浏览进度，打卡是用户主动标记，互不替代。

---

## 三、技术架构

- **微信原生小程序**（WXML / WXSS / JS），不引入任何第三方 UI 框架
- **数据内置**：三景区数据写死在 `data/spots.js`，严格照需求文档，未做任何扩写
- **本地状态**：进度与打卡通过 `wx.*Storage` 同步读写，全局共享（`utils/progress.js`）
- **纯前端**：无任何云开发、无 `wx.request`、无定位 / 支付 / 分享等需后端的接口

---

## 四、离线设计（核心亮点）

1. **零网络依赖**：小程序运行全程不发任何网络请求，景点浏览、打卡、进度统计全部本地完成。
2. **资源本地化**：封面图下载后内置 `images/`，列表项通过 `mode="aspectFill"` 内联，离线渲染。
3. **性能约束落地**：列表项节点数严格 ≤ 5（`view + image + name + meta`），保证长列表流畅。
4. **状态可恢复**：进度 / 打卡写入本地缓存，进程退出再进入精确恢复，不丢数据。

> 这意味着：只要小程序包在手机上，后续浏览**完全离线**；仅「首次打开 / 扫码」那一下需要联网拉取。

---

## 五、工程化与质量门禁

- **验收契约**：`acceptance/contract.yaml` 用机器可消费的契约描述 8 条验收点 + 5 条实现约束，含真机验证条目与已知限制。
- **8 条自动化断言**：基于官方 `miniprogram-simulate` + `jest` + `jsdom`，一条命令跑完全部断言，**当前全绿**。
- **CI 强制门禁**：`.github/workflows/ci.yml` 在 push / PR 时自动运行 `npm ci` + `npm test`，并对主包体积做 2MB 上限检查。
- **5 条实现约束**全部落实：① 仅用 `setData` ② 路径式 `setData` ③ 同步本地缓存 ④ `wx:if` 空状态（非样式隐藏）⑤ 列表项 ≤ 5 节点。

## 六、如何运行与分享

### 6.1 本地预览（开发自测）

```bash
npm install
npm test            # 跑 8 条验收断言
npm run preview     # 生成 390px 移动端预览页 + 截图
```

微信开发者工具中：导入项目 → 目录选本仓库 → AppID 见 `project.config.json` → 后端服务选「不使用云服务」→ 点「预览」扫码。

### 6.2 分享演示（体验版）

1. 开发者工具点「上传」→ 代码提交到微信后台（仅上传，**不发布**）
2. 微信公众平台 → 开发管理 → 将开发版本「设为体验版」+ 添加体验者微信号
3. 体验者扫**体验版二维码**即可打开；官方时效 7 天，手机缓存包后断网也可进

> 仅上传不上线，运行仍 100% 本地离线，符合「不接后端」定位。

### 6.3 自动化验收

`npm test` 即跑 `test/acceptance.test.js` 的 8 条断言，覆盖渲染、状态恢复、空状态、条件渲染、视口等。

## 八、验收对照表

**5 条实现约束**

| 编号 | 约束 | 落点 |
|---|---|---|
| ① | 仅用 `setData` 更新视图 | 页面 `onLoad` / 交互后统一 `setData` |
| ② | 路径式 `setData` | `setData({ 'spots[i].progress': x })`（人工核查） |
| ③ | 同步本地缓存 | `getStorageSync` / `setStorageSync` |
| ④ | `wx:if` 空状态 | 空数据渲染 `null` 节点，非样式隐藏 |
| ⑤ | 列表项 ≤ 5 节点 | 列表项 4 节点（view+image+name+meta） |

**8 条自动化断言**

1. 列表页渲染景区条目数 = 3
2. 直接改 `this.data` 不调 `setData` → 渲染查不到被改文字
3. 进入西湖逐段浏览到末段，景点名与内置 5 个完全一致、顺序一致
4. 西湖浏览到第 2 个后回列表 → 文案含「已浏览 40%」
5. 写入进度后重挂载并从缓存恢复，恢复序号与退出前严格相等
6. 数据为空时空状态含「暂无」；非空时该节点为 `null`
7. 条件渲染条件为假时节点为 `null`（非样式隐藏）
8. 390px 视口预览页：条目数 = 3 且西湖「已浏览 40%」
